SKy Fit quraşdırılması

  1. Supabase layihəsi yaradın.
  2. supabase/database.sql faylını SQL Editor-da tam run edin.
  3. Project Settings → API hissəsindən URL və anon key götürün.
  4. js/config.js faylında həmin məlumatları yazın.
  5. Authentication → URL Configuration hissəsində GitHub Pages URL-ni Site URL və Redirect URL kimi əlavə edin.
  6. İlk hesabı register.html ilə yaradın. Sonra SQL Editor-da update public.profiles set role='admin' where email='EMAILINIZ'; run edin.
  7. GitHub-a bütün qovluğu yükləyin və Pages-i aktiv edin.
