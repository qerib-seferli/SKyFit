1-ci mərhələ

Supabase quraşdırılması

Verilənlər bazası, Auth, Storage, RLS və Realtime bu mərhələdə hazırlanır.

01

SQL faylını işlət

Supabase Dashboard daxilində SQL Editor açın və yekun database SQL kodunu bütöv şəkildə Run edin.

Fayl
supabase/database.sql
Tamamlanıb
02

API məlumatlarını əlavə et

Supabase Project Settings → API bölməsindən Project URL və anon public key məlumatlarını götürün.

js/config.js 
SUPABASE_URL:
'https://elpwornsvnplyzyufqir.supabase.co'

SUPABASE_ANON_KEY:
'Anon public key'

SITE_URL:
'https://qerib-seferli.github.io/SKyFit'
Frontend daxilində yalnız anon public key istifadə olunur. Service role key heç vaxt GitHub-a yazılmamalıdır.
03

Auth URL-lərini qur

Supabase Authentication → URL Configuration bölməsində aşağıdakı ünvanları əlavə edin.

Site URL
https://qerib-seferli.github.io/SKyFit
Redirect URL
https://qerib-seferli.github.io/SKyFit/**
Şifrə bərpası
https://qerib-seferli.github.io/SKyFit/update-password.html
04

İlk admin hesabını yarat

Əvvəlcə register.html səhifəsindən öz hesabınızı yaradın. Sonra SQL Editor-da həmin emaili admin roluna dəyişin.

SQL 
update public.profiles
set role = 'admin'
where email = 'SENIN_EMAILIN';
Email ünvanını öz real qeydiyyat emailinizlə dəyişin.
2-ci mərhələ

GitHub Pages deploy

Layihə statik frontend kimi GitHub Pages üzərində işləyir.

Repository məlumatı

GitHub istifadəçi adı qerib-seferli
Repository adı SKyFit
Branch main
Deploy qovluğu / root

GitHub Pages addımları

  1. Repository → Settings bölməsini aç.
  2. Sol menyudan Pages seç.
  3. Source olaraq Deploy from a branch seç.
  4. Branch: main, Folder: / root seç.
  5. Save düyməsinə bas.
Hazır sayt ünvanı https://qerib-seferli.github.io/SKyFit/
